# 网络新词情感词典构建与自动标注

## 项目背景
针对社交媒体文本（小红书/微博），传统情感词典对网络新词（yyds、绝绝子、破防等）识别率低，本项目构建了一个面向网络新词的情感词典，并实现了自动标注与评测。

## 数据说明
- 数据来源：模拟小红书评论 50 条
- 数据内容：包含正面、负面、中性三种情感，含大量网络新词

## 方法与实现
- 分词工具：基于关键词匹配
- 情感词典：手工构建，收录 50+ 网络新词
- 标注规则：情感词优先匹配，非中性词覆盖前面的判断
- 评测方式：人工标注 50 条作为标准答案，计算准确率

## 实验结果
- 初版准确率：65.3%
- 优化后准确率：**94.0%**
- 主要优化手段：扩充词典、调整匹配优先级、反讽短语识别

## 项目文件说明
- `sentiment_lexicon.py`：情感词典（50+ 网络新词）
- `auto_label.py`：自动标注脚本
- `comments_labeled.csv`：标注结果（含自动标注和人工标注）
- `calc_accuracy.py`：准确率计算脚本
