# V1 词典基线（历史版本，仅作迭代对照）

本目录保留项目**第一版（V1）**的原始代码，用于真实展示"65.3% → 94%"质量迭代的起点。

## 为什么保留旧代码？

V1 是一个"会吵架的词典"：每个网络新词只对应一个固定极性，不看语境。它会把"被暖得破防了"判成负面、把"排队两小时就这？绝绝子"判成正面。**正是这些错误驱动了后续两轮规则迭代。** 保留 V1，是为了让迭代过程可复现、可对照，而不是用一份凭空出现的精致代码掩盖踩坑过程。

## 与当前版本的关系

| | 本目录（V1 基线） | 当前版本（V3） |
|---|---|---|
| 词典 | `sentiment_dict.py`（一词一极性，约 50 词） | `data/sentiment_lexicon.csv`（极性+强度+语境依赖标记） |
| 标注逻辑 | 取最后匹配的非中性词 | `src/annotate.py`（三维输出+否定/转折/反讽规则+置信度） |
| 反讽 | ❌ 不识别 | ✅ 期望违背信号检测 |
| 多义/语境 | ❌ 固定极性 | ✅ 语境依赖词 + 低置信度转人工 |
| 否定 | ❌ 不处理 | ✅ 否定词计数 |
| 一致率 | 65.3%（150 条验证集） | 94.0% |

## 文件说明

- `sentiment_dict.py`：V1 情感词典（已去除重复 key，逻辑未改动）
- `auto_label.py`：V1 自动标注脚本（硬编码本机路径已改为相对路径）
- `calc_accuracy.py`：用 V1 逻辑对金标准复算一致率并打印错误明细
- `sample_comments.csv`：V1 演示用评论样例（含多条会触发 V1 误判的反讽/语境样本）
- `v1_demo_gold.csv`：**边界难例集**（20 条，含人工标注与错误类型），集中收录 V1 会翻车的反讽/多义/多重否定/词典遗漏样本，用于直观演示 V1 缺陷

## 运行

```bash
cd legacy/v1_dict_baseline
python auto_label.py        # 对 sample_comments.csv 做 V1 标注，可观察误判
python calc_accuracy.py     # 对 v1_demo_gold.csv 难例集复算，V1 一致率明显偏低（预期）
```

> **关于数字口径（重要，避免误读）：**
> - V1 的 **65.3%** 是项目初期在 **150 条随机验证集**上的历史一致率；
> - `v1_demo_gold.csv` 是**刻意收集的 V1 失败/边界样本**，不是随机抽样，所以 V1 在它上面的一致率会远低于 65.3%，这正是用来展示"V1 错在哪、为什么要迭代"的；
> - 仓库根目录的 `ground_truth.csv`（50 条）是项目后期沉淀的样例，用后期补过词的 V1 词典去跑会偏高，**不代表 V1 真实水平**，请勿用它论证 V1 效果。
> - 完整错误归因见 `../../data/error_analysis.csv`，最新评估见 `../../src/evaluate.py`。
